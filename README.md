🚗 Neon Road Jumper (или твое название)
Динамичная 2D-аркада на Unity 6, где игрок управляет машинкой, прыгающей по бесконечным дорогам. Проверь свою реакцию и точность, избегая столкновений с трафиком!

🎮 Геймплей
Движение: Машинка автоматически перемещается из стороны в сторону по горизонтали (Ping-Pong movement).

Прыжок: Нажми и удерживай для прыжка. Длительность нажатия определяет высоту прыжка.

Цель: Запрыгивай на новые дороги выше тебя, чтобы набирать очки.

Опасность: Избегай столкновений с вражескими машинками. Одно касание — Game Over!

🛠 Технологии и Архитектура
Проект разработан с упором на SOLID и высокую производительность:

Unity 6 (6.3+): Использование последних возможностей движка.

Input System Package: Современная обработка ввода.

Object Pooling: Оптимизированная генерация дорог и врагов для предотвращения лагов.

Scriptable Objects: Гибкая настройка баланса игры (скорость, сила прыжка) без правки кода.

Decoupled Architecture: Логика разделена на независимые компоненты:

PlayerController - физика и перемещение.

PlayerDamageHandler — система столкновений.

PlayerProgressTracker — учет прогресса и счета.
